# 소망이 닿는 밤 · LOTTE 2027

개인 테스트용 모바일 픽셀 웹게임입니다. HTML/CSS/JavaScript로 동작하며 진행 상황은 각 브라우저에 저장됩니다.

## 로컬 실행

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start
```

접속 주소: http://127.0.0.1:4173

macOS에서는 `게임 실행.command`를 더블클릭해도 됩니다. 서버 종료는 Control+C입니다. 다른 포트는 `PORT=4174 npm start`로 지정합니다.

## 게임 흐름

- 크리스마스마켓 월드광장 → 타워 앞 → 1층에서 등반 시작.
- 뒷모습 캐릭터가 벽을 오릅니다. 연타를 받으며 이벤트마다 이동량이 1~6층으로 증가합니다.
- 22층 빼빼로, 40층 가나 핫초코, 60층 불고기버거, 83층 칠성사이다, 102층 자일리톨과 휘바휘바 춤.
- 이벤트 층을 건너뛰지 않으며 1층에서 123층까지 등반 입력은 총 51회입니다.
- 칠성사이다를 나누면 햇님과 초록별·여섯 흰 별을 만나 아이콘을 얻습니다.
- 123층에서 개인 소망을 입력하고 선택 결과에 따라 호텔 또는 눈사람 결말로 진행합니다.
- 호텔은 입구 → 거실 → 객실 → 창가 순서입니다.
- 한국 시간 2027년 1월 1일 자정에 소망 불꽃이 표시됩니다. 불꽃 미리 보기도 가능합니다.
- 쿠폰은 실제 발급·사용 기능이 없는 시제품입니다. 음악은 포함하지 않습니다.

## 테스트

```sh
npm test
```

등반·이벤트 정차·결말·저장 복구·입력 보호·댄스 동작을 검사합니다.

저장된 진행에 영향을 주지 않는 미리보기:

- `/?preview=start`: 처음부터
- `/?preview=climb&floor=1`: 등반
- `/?preview=dance`: 102층 춤

## Vercel 배포

정적 배포 대상은 `dist`입니다. GitHub 저장소를 가져온 뒤 Framework Preset은 Other, Output Directory는 `dist`, Build Command는 비워두세요. `server.mjs`는 로컬 실행용입니다.

## 폰트와 저장

갈무리14·11은 jsDelivr CSS에서 로드하므로 인터넷 연결이 필요합니다. 별도 AI API나 데이터베이스는 사용하지 않습니다. 소망과 진행은 브라우저 로컬 저장소에 저장하며 다른 기기로 동기화되지 않습니다. 자정 연출은 기기 시각을 기준으로 합니다.

로컬 설정, 환경변수 파일, 디자인 검토 자료는 Git에서 제외합니다.
